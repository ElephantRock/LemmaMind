# M−1 Pilot Evaluation

This directory becomes LemmaMind's first manually judged evaluation corpus.

Record:

- whether observations are supported, partially supported, unsupported, or contradicted
- whether proposed patterns genuinely instantiate across member repositories
- whether an insight influenced an engineering/research decision
- review time and friction
- false positives and low-signal outputs

The M−1 corpus should be preserved after the pilot and reused to evaluate later automated extractors and reasoners.
