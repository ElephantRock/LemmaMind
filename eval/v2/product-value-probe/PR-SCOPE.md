# V2-P0 Change Scope

This branch changes product/evaluation policy only. It does not add autonomous capture, scheduler behavior, semantic change interpretation, embeddings, model reasoning, promotion authority, or action execution.

The branch:

1. closes stale README wording after V1;
2. defines the prospective V2-P0 product-value gate;
3. provides immutable interval/closeout evaluation templates;
4. records the first five-repository prospective baseline;
5. waits for later real revisions before any V2-P0 interval is scored.
